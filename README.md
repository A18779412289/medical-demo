# medical-demo
医疗信息后台管理系统

## 📌 项目简介
基于Vue2 + ElementUI开发的医疗后台Demo，用于医院基础信息可视化管理。实现页面布局、菜单路由、数据看板、信息表单等基础后台功能，使用ECharts完成医疗统计图表展示。

## 🛠 技术栈
- Vue2
- Element UI
- Vue Router
- ECharts
- Axios
- JavaScript / HTML / CSS

## ✨ 功能模块
1. 首页数据看板：利用ECharts展示门诊量、患者统计可视化图表
2. 侧边栏动态菜单路由，多页面切换
3. 信息管理页面：列表展示、查询、基础表单录入
4. 后台通用布局（顶部导航 + 侧边菜单 + 主内容区）
